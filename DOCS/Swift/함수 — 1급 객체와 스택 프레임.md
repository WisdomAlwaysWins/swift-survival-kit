#swift #function #memory #interview 

>[!info] 함수, 왜 중요할까?
>Swift는 함수를 `Int`나 `String`처럼 **하나의 값으로 취급**한다. 변수에 담을 수 있고, 다른 함수에 넘길 수 있고, 함수가 함수를 만들어서 돌려줄 수도 있다. 이걸 "**1급 객체**"라고 부른다.

## 1. 개념 정리
#### 1.1 함수 타입 (Funcion Type)

>[!abstract] 함수 타입이 뭔데?
>`Int`, `String`이 타입인 것처럼, 함수에도 타입이 있다. 함수 타입은 **"이 함수가 뭘 받고 뭘 돌려주는지"**를 나타낸다.
>- `(Int, Int) -> Int` → Int 2개를 받아서 Int를 돌려주는 함수
>- `() -> ()` → 아무것도 안 받고 아무것도 안 돌려주는 함수

Swift에서 모든 함수는 **함수 타입**을 가진다. 함수 타입은 `(파라미터 타입) -> 리턴 타입` 형태로 표현된다.

```swift
func add(a: Int, b: Int) -> Int { return a + b }
// add의 함수 타입: (Int, Int) -> Int

func sayHi() { print("Hi") }
// sayHi의 함수 타입: () -> Void
```

>[!warning] 함수 타입에 Argument 레이블은 포함되지 않는다!
>`add(a:b:)`의 타입은 `(Int, Int) -> Int`이지, `(a: Int, b: Int) -> Int`이 아니다. 그래서 변수에 할당한 후에는 레이블 없이 호출한다.
>```swift
>let function: (Int, Int) -> Int = add
>function(10, 20) // 레이블 없이 호출 👍
>function(a: 10, b: 20) // 컴파일 에러 🚩
>/// - error: extraneous argument labels 'a:b:' in call
>```

#### 1.2 Parameter vs Argument

| 구분        | 의미          | 예시                                   |
| --------- | ----------- | ------------------------------------ |
| Parameter | 함수 정의 시 변수  | `func greet(name: String)` 에서 `name` |
| Argument  | 함수 호출 시 전달값 | `greet("Jihye")` 에서 `"Jihye"`        |

```swift
// Argument Label (외부명) vs Parameter Name (내부명)
func greet(to name: String) {
	// to: argument label → 호출 시
	// name: parameter name → 함수 내부에서
	print("Hello, \(name)")
}

greet(to: "Jihye")
```

```swift
// 와일드카드로 레이블 생략 가능
func add(_ a: Int, _ b: Int) -> Int { return a + b }

add(10, 20) // 레이블 없이 호출!
```

#### 1.3 1급 객체 (First-Class Object)

>[!abstract] 1급 객체가 뭔데?
>프로그래밍에서 **1급 객체**란, 그 언어에서 "값"으로 대우받는 것을 말한다.
>예를 들어, `Int`는 당연히 1급 객체다 — 변수에 담을 수 있고, 함수에 넘길 수 있고, 함수가 리턴할 수 있다. 스위프트에서는 함수도 이와 똑같이 변수에 담고, 넘기고, 리턴할 수 있다. 그래서 **"함수는 1급 객체"**라고 한다.

스위프트의 **함수는 1급 객체**다! 구체적으로 3가지 조건을 만족한다:

1. 변수에 할당 가능
2. 함수의 매개변수로 전달 가능
3. 함수의 반환값으로 사용 가능

```swift
func multiply(a: Int, b: Int) -> Int { return a * b }

let operation: (Int, Int) -> Int = multiply
let result = operation(6, 5) // 30
```

```swift
func execute(_ op: (Int, Int) -> Int, _ a: Int, _ b: Int) -> Int {
	return op(a, b)
}

func add(_ a: Int, _ b: Int) -> Int { return a + b } 
func mul(_ a: Int, _ b: Int) -> Int { return a * b }

execute(add, 12, 13) // 24
execute(mul, 12, 13) // 156
```

```swift
func makeMultipliter(factor: Int) -> (Int) -> Int {
	return { value in
		return value * factor
	}
}

let doubler = makeMultiplier(factor: 2)
let tripler = makeMultiplier(factor: 3)

double(5) // 10
tripler(5) // 15
```

>[!question] `-> (Int) -> Int` 이 형태는 뭔데 .. ?
>`->`는 스위프트에서 함수를 뜻하는 표기법이다. 타입을 적는 자리에 `->`가 있으면, 함수 타입이라는 뜻.
>```swift
>let transform: (Int) -> Int = { value in value * 2 }
>```
>```swift
>(Int) -> Int
>// 받는 것: Int
>// 돌려주는 것: Int
>```
>몇 가지 예시를 보면,
>```swift
>Int // 그낭 정수
>(Int) -> Int // Int를 받고 Int를 돌려주는 함수
>(String) -> Void // String을 받고 Bool 돌려주는 함수
>() -> Void // 아무것도 안 받고 아무것도 안 돌려주는 함수
>```
>`makeMultiplier(factor:2)`를 호출하면 `{ value in value * 2 }`라는 함수가 나옵니다.
>리턴 타입이 `(Int) -> Int`인 것!

>[!tip] 1급 객체 = 클로저의 근거
>함수가 값처럼 전달될 수 있으니, 이름이 없어도 변수에 담아서 전달 할 수 있다. 
>이것이 **클로저(이름 없는 함수)**가 존재할 수 있는 이유!

#### 1.4 중첩 함수 (Nested Functions)

```swift
func outerFunction() {
	var outerValue = 10
	
	func innerFunction() {
		print(outerValue) // 외부 변수 접근 가능 (캡처)
	}
	
	innerFunction() // 10 출력
}

// innerFunction() // 외부에서 접근 불가 🚩
```

- 중첩 함수는 외부 함수의 스코프 안에서만 존재한다
- 바깥 함수의 변수에 접근할 수 있다 → 이것을 **캡처(capture)** 라고 부른다

>[!abstract] 캡처가 뭔데?
>함수가 자기 바깥에 있는 변수를 붙잡아서 사용하는 것을 캡처라고 한다.
>
>위 예시에서 `innerFunction`은 자기 안에 `outerValue`가 없는데도 쓸 수 있다 — 바깥 함수의 변수를 캡처했기 때문이다. 세부 내용은 클로저할 때... (coming soon)

#### 1.5 inout 매개변수

```swift
func swapValues(_ a: inout Int, _ b: inout Int) {
    let temp = a
    a = b
    b = temp
}

var x = 10, y = 20
swapValues(&x, &y)  // & 필수
print(x, y)         // 20, 10
```

## 2. 메모리 동작 — 스택 프레임

#### 2.1 스택 프레임이란?

함수가 호출될 때 메모리의 스택 영역에 만들어지는 함수 전용 작업 공간이다. 함수가 필요한 모든 것(파라미터, 지역 변수, 돌아갈 주소)이 여기에 저장된다. 함수가 끝나면 이 공간이 통째로 사라진다.

- Return Address — 함수 실행 후 돌아갈 코드 위치
- Parameters — 전달받은 파라미터 값
- Local Variables — 함수 내 지역 변수

#### 2.2 동작 과정


```swift
func add(a: Int, b: Int) -> Int {
    let result = a + b       // 3
    return result            // 4
}

func main() {
    let x = 10               // 1
    let y = 20
    let sum = add(a: x, b: y) // 2
    print(sum)                // 5
}
```

1. `main()` 호출 → main 프레임 생성
2. `add(a:b:)` 호출 → add 프레임이 위에 쌓임
3. `result = 30` 계산
4. `return result` → add 프레임 pop
	- 반환값 30이 main의 sum에 저장
	- add 프레임의 메모리는 자동으로 사라짐
5. `print(sum)` → main도 종료 → 스택 비워짐

## ❓ 스스로에게 물어봐

Q1. 스위프트에서 함수가 1급 객체라는 것은 무엇을 의미하나요?

>1급 객체란 함수를 값처럼 다룰 수 있다는 뜻입니다. 
> 
> 1. 변수에 할당 가능
> 2. 함수의 파라미터로 전달 가능
> 3. 함수의 반환값으로 사용 가능

Q2. 함수가 호출될 때 메모리에서 어떤 일이 일어나나요?

>함수가 호출되면 스택 프레임이 생성됩니다. 새 프레임 공간에 파라미터 값, 리턴 주소 등이 저장됩니다. 함수가 반환되면 프레임이 사라집니다.
